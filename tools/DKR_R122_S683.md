# S6.8.3 — Extended numerical qualification (GGUF)
Uses fixed Candle 08a36261 and existing qualified external PTX. One archive
of mistralrs-core tests, one extended test in two independent processes.
The S6.8 seal is checked against all original artifacts before building.
No changes to CUDA code, Cargo.lock, production profile, or CI.

51 CPU dequantization comparisons using exactly the same quantized bytes
(Candle CPU implementation vs GPU; not a separate third-party codec).
300 sequential shape/dtype cases (10 codecs x 10 batch/shape pairs x 3 dtypes),
one full-width Q4K 2048x2048 projection, 48 concurrent cases (2 modes x
4 workers x 6 rounds), each executed twice. CPU f64 dot checks on selected
evenly spaced rows/columns with analytical activation and dtype rounding bounds;
all output elements undergo A/B comparison and exact repetition. CPU weights
are decoded from CPU quantized bytes, not the GPU output; readback proves bytes
match. We deliberately sample dot products for larger shapes to limit CPU
cost. This is not a timing benchmark. Concurrency uses shared Candle device
per-thread streams and separate Candle device handles with explicit streams;
these may share a driver primary context. Distinct driver context isolation
is not claimed. No test-only error masking. Successful report is scoped to
GGUF matrix, not all operations or production.

Run (clean persistent worktree; prior S6.8 seal must be present):
    export DKR_S6_ORIGINAL_REPO="$HOME/tmp/mistralrs_provider/mistral.rs"
    bash tools/dkr_r122_s683_local.sh --preflight
    DKR_APPROVE_S683=1 bash tools/dkr_r122_s683_local.sh

Both A/B run even if either fails. Rerunning reuses the new archive when
its build fingerprint matches. A/B tolerance predeclared per dtype.
Prior reports are not modified. Pending: real model logits/generation,
concurrency with distinct underlying driver contexts, broader non-GGUF
